# Security

This is an early preview. Only the latest commit on `main` is supported. There is no stable release and no response-time guarantee.

Report vulnerabilities privately, by either route:

- GitHub private vulnerability reporting: open this repository's **Security** tab and choose **Report a vulnerability**.
- Email: [hello@morrowdock.app](mailto:hello@morrowdock.app), the project's security contact.

Do not open public issues for exploits, credentials or personal data. Include the affected commit, the impact, a reproduction with synthetic data only, and a reply route. Maintainers triage, coordinate remediation and agree on disclosure timing with the reporter.

Never include real credentials, learner data or private course material in a report.
