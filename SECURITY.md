# Security

This is an early preview. Only the latest commit on `main` is supported. There is no stable release and no response-time guarantee.

Report vulnerabilities privately to [hello@morrowdock.app](mailto:hello@morrowdock.app), the current owner-approved fallback security contact. Do not open public issues for exploits, credentials or personal data. Include the affected commit, the impact, a reproduction with synthetic data only, and a reply route. Maintainers triage, coordinate remediation and agree on disclosure timing with the reporter.

Planned dedicated security address: `security@morrowdock.app`. Alias setup is pending owner confirmation; until this file names it as active, use `hello@morrowdock.app` above.

Never include real credentials, learner data or private course material in a report.
