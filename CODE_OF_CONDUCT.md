# Code of conduct

Treat contributors respectfully; no harassment, discrimination, threats, sexualized conduct, doxxing or retaliation. Maintainers may remove content, restrict access or suspend participants, proportionate to severity; offer an appeal to an uninvolved maintainer where possible.

Report conduct concerns privately to [hello@morrowdock.app](mailto:hello@morrowdock.app), the owner-approved Code of Conduct contact. Do not post sensitive reports in issues. Before release, confirm mailbox monitoring and designate an enforcement owner and appeal route.
